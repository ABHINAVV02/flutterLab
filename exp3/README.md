# Experiment 3: Simple Calculator

## Overview

A functional calculator application that performs basic arithmetic operations (addition, subtraction, multiplication, division).

## Purpose

This project demonstrates:

- Text input and data validation
- State management with setState
- Mathematical operations
- Error handling and user feedback
- Dynamic UI updates

## Features

- ✓ Addition (+) operation
- ✓ Subtraction (-) operation
- ✓ Multiplication (\*) operation
- ✓ Division (/) operation
- ✓ Input validation
- ✓ Error messages via SnackBar
- ✓ Real-time result display

## Getting Started

### Installation

```bash
cd exp3
flutter pub get
```

### Running

```bash
flutter run
```

## How to Use

1. Enter first number in the input field
2. Enter operator (+, -, \*, /)
3. Enter second number
4. Tap Calculate button
5. Result will be displayed below
