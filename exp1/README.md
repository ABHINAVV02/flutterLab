# Experiment 1: Hello World

## Overview

A basic Flutter introduction application that displays a simple "Hello World" message on the screen.

## Purpose

This is a foundational Flutter project designed to demonstrate:

- Basic Flutter app structure
- Building simple UI with MaterialApp and Scaffold
- Creating centered text widgets
- Using AppBar as a header

## Features

- ✓ Simple Hello World display
- ✓ Centered AppBar with title
- ✓ Clean, minimalist UI
- ✓ Single-page application

## Getting Started

### Installation

```bash
cd exp1
flutter pub get
```

### Running

```bash
flutter run
```

## Technologies Used

- Flutter 3.x
- Dart 3.x
